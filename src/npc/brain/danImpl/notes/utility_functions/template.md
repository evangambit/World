## Template for new entries

```
## Entry N — <one-line mechanism> → <implied form>

Setup.            <the problem in 1–2 sentences>
Flags.            dynamics · discounting · floor · uncertainty · horizon · transit cost
Implied utility.  u(x) = …
Marginal value.   u'(x) = …   ← the real signature; note behavior at 0 and in the tail
Mechanism.        why this structure forces this form (the transferable asset)
Derived vs        which features fall out of the dynamics (rigorous) vs
  imported.       which are taste/analogy (the soft joints)
Transfers /       where the mechanism carries over, and the flag-flip that breaks it
  breaks.
```

**Reminder for every entry:** the honest output of this library is often "you're in a
combination no single catalogued form covers — solve it." Discounting *and* death *and*
uncertainty together give something CARA-ish in the bulk, barrier-singular at zero,
risk-shaped by the noise — unreadable off any one row here.
